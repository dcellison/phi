# The relativizer `wha`

**wha** opens a clause that modifies a following noun or, when the head is implicit, occupies a noun-phrase position by itself.

## Saying `wha`

One syllable, fully stressed. Round the lips and raise the back of the tongue as though for **w**, then send voiceless breath through the narrowing for **wh**. The lips relax and the jaw falls open as the voice arrives on **a**: /ˈʍä/. The movement is a pronunciation path, not a second grammar hidden inside the word.

## Headed structure

A headed relative has this shape:

```
[wha CLAUSE] NOUN
```

Everything after **wha** and before the head noun belongs to the description.

```
wha nophi kealo miona ha nai.
REL story create person PROX be.
(The person who creates stories is here.)
```

```
mia wha mia to theo shelu lothea.
1SG REL 1SG PST read book love.
(I love the book that I read.)
```

```
wha mua shelira nai ruela mioru nai.
REL LOC forest be path beautiful be.
(The path that is in the forest is beautiful.)
```

## Why there is no closer

The complement frames **tha ... tho**, **pha ... pho**, and **sha ... sho** need an explicit closing word before the matrix predicate. A headed **wha** clause ends at its head noun. In **wha mia to theo shelu**, the relative predicate **theo** completes before **shelu** arrives as the book that was read.

Headless relatives still keep **wha**, but context supplies the missing head. Their noun-phrase position marks where the construction ends; Chapter 20 closes with that pattern.

## The gap

The head noun is absent from one role inside the relative clause. A schematic gap makes the relation visible:

```
wha mia ___ to theo shelu.
REL 1SG [gap] PST read book.
"the book that I read" (noun phrase).
```

The gap occupies object position. In the next phrase it occupies subject position:

```
wha ___ nophi kealo miona.
REL [gap] story create person.
"the person who creates stories" (noun phrase).
```

**wha** does not change form according to the missing role.

If a preposition governs the gap, the preposition remains where Phi normally places it:

```
mia wha mia mua to thalo shelira lothea.
1SG REL 1SG LOC PST walk forest love.
(I love the forest that I walked in.)
```

Inside the relative clause, **mua** still precedes the gap in its object position. The head **shelira** stands outside that clause and follows the whole description; it refers to the same place as the gap without becoming a postposed prepositional object.
